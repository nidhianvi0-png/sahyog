# Sahyog – Skill Exchange Hub

A platform where people exchange skills with each other — teach what you know, learn what you don't!

## Features
- 🤝 Smart Skill Matching
- 👤 Skill Profiles
- 💬 In-App Chat
- ⭐ Rating System
- 🏅 Achievement Badges
